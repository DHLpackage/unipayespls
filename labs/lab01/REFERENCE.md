# Notification: справка по объектам

Здесь описаны данные и методы сервиса. Нужные изменения для ЛР1 перечислены в [TASK.md](TASK.md).
Часть методов уже реализована в заготовке, остальные добавляются по мере выполнения работ.

## Данные и поведение

Сервис уведомлений формирует квитанцию об отправке и сохраняет её в памяти. Реальные письма и SMS не отправляются.

| Объект | Назначение |
|---|---|
| `Recipient(email=None, phone=None, push_token=None)` | Готовые неизменяемые контакты получателя. Достаточно контакта выбранного канала. |
| `Notification(recipient, message)` | Получатель и непустой текст после удаления пробелов по краям. |
| `DeliveryReceipt(channel, destination, text)` | Готовая неизменяемая квитанция об отправке. |
| `Outbox` | Готовый журнал отправок в памяти. |

Общий интерфейс — `NotificationSender.send(notification) -> DeliveryReceipt`. `EmailSender` использует `email`, `SmsSender` — `phone`. Отсутствующий контакт вызывает `DomainError('MISSING_CONTACT')`; полный формат адреса не проверяется.

`NotificationService.send(channel, notification)` выбирает отправителя из отображения, вызывает его один раз и сохраняет проверенную квитанцию после успешного вызова. Метод `sent() -> tuple[DeliveryReceipt, ...]` возвращает журнал.

Каналы `EMAIL`, `SMS`, `PUSH` предусмотрены заранее. Неизвестный или неподключённый канал вызывает `UNSUPPORTED_CHANNEL`. Повторный явный вызов создаёт новую квитанцию; автоматических повторов нет. Все отправители возвращают один тип результата.

## Работа с готовым кодом

Обращение к сервису выполняется через `app/api.py`. Разрешённые файлы указаны в [TASK.md](TASK.md).
Проверки используют подготовленные данные и не зависят от работы других групп.

До ЛР5 сборка предоставлена готовой. Нужные объекты могут создаваться в сервисном модуле; `assembly.py` менять не нужно.

## Ошибки и результаты

`DomainError` содержит код ошибки. При отказе проверки состояние объекта не должно меняться.
Ошибка переданной зависимости не заменяется успешным результатом. Конкретные коды и примеры
приведены в задании и открытых тестах.
